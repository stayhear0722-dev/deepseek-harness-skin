# Agent Note: Ambient conversation atmosphere for the web client

Status: implemented

[English](2026-08-16-web-conversation-atmosphere.md) | 中文

## Problem

默认的对话列保持中性，但在 Harness 空闲时缺少“正在待命”的视觉感；长任务流式输出时，内容与背景的分离也不够明显。目标是在对话等待时提供安静、可交互的背景，在任务运行时提供易读的玻璃表面，同时不改变会话协议，也不与对话控件争夺控制权。

## Decision

`@deepseek-ai/dsh-client-ui-conversation` 在 `ConversationRoot` 内渲染 `HarnessAtmosphere`。该组件只拥有一个不参与交互命中的 OGL 画布：仅在指针位于对话列内时采样指针位置，并读取现有投影中的 `session.running`。着色器绘制低密度蓝色粒子与缓慢漂移的雾带；移动指针会产生局部涟漪。用户启用“减少动态效果”或浏览器没有 WebGL 时，效果会自动关闭。

既有对话插槽仍保留在原有的前景层中。当投影会话处于运行状态时，根节点添加 `data-running`，并在内容和画布之间显示一层半透明、模糊的 CSS 面板。相邻侧边栏使用更深的蓝色外壳和浅色导航控件，使整个应用框架成为一个统一界面，而不是在背景旁放置白色面板。这只是表现层改动：不新增插槽、配置项、事件、持久化记录或模型可见状态。

着色器会读取 HeroShell 已渲染的官方 DeepSeek 鱼形 SVG，并在空闲输入框后方以更密集的青蓝色粒子还原该标志。它仍属于同一套会受指针波纹扰动的粒子场，而不是图片素材或独立场景，因此标志会随现有交互产生漂移与局部散开的效果。

## Alternatives considered

- **使用现成的粒子组件。** 未采用，因为可用预设会得到通用星空效果，并带来与对话状态无关的交互行为。小型 OGL 着色器能让美术和运动逻辑只留在唯一需要它的界面中。
- **使用完整的 Three.js 场景。** 未采用，因为这里仅需要一张背景平面，不需要场景图、相机或素材管线。OGL 更小，也避免再引入一层 React 渲染抽象。
- **单独的加载遮罩。** 未采用，因为它会产生新的焦点和布局所有权。根节点伪元素复用已投影的运行状态，并让转录区和输入框继续留在现有树中。

## Consequences

空闲和空白对话界面获得可交互的视觉锚点；任务运行时获得更强的可读性，同时不会阻挡输入、文本选择或扩展插槽。画布将设备像素比限制在 1.5，并在卸载时彻底移除，以限制图形开销。

效果依赖浏览器的 WebGL 实现。没有 WebGL，或用户偏好减少动态效果时，界面会保留普通主题背景且不播放动画。OGL 会成为对话包打包的、采用宽松许可证的第三方依赖。

## Testing

`skeleton.client.spec.tsx` 断言现有投影中的运行状态能够打开和关闭视觉状态，且不改变常驻对话行为。包构建会将 OGL 层与客户端入口一同编译。
